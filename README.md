Tailwind CSS Demo Site

🚀 Getting Started
1. Install dependencies
npm install

2. Run development server
npm run dev

3. Build for production
npm run build

4. Preview production build
npm run preview

🌐 Deployment

The project is deployed on Netlify using the production build generated by Vite.

Build command: npm run build

Publish directory: dist

✨ Purpose

This project serves as a simple Tailwind CSS demo site to showcase styling, layout, and a basic Vite setup.
